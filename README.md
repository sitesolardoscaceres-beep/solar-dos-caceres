# Solar dos Cáceres — site

Site estático (HTML/CSS/JS, sem build).

- `index.html` — página principal
- `content.js` — conteúdos editáveis (preços, quartos, contactos, fotos)
- `admin.html` — área de administração; grava `content.js` (e fotos em `img/`) neste repositório via API do GitHub
- `privacidade.html`, `cookies.html`, `termos.html` — páginas legais

Alojamento: Cloudflare Pages ligado a este repositório (cada gravação no admin publica o site em 1–2 minutos).
