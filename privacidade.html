Política de Privacidade (RGPD)

1. Responsável pelo Tratamento de Dados

O responsável pelo tratamento dos dados é:

Solar dos Cáceres

2. Dados Recolhidos

Podemos recolher:

  • Nome
  • Email
  • Número de telefone
  • Dados de navegação (cookies)

3. Finalidade

Os dados são utilizados para:

  • Responder a contactos
  • Melhorar a experiência do utilizador
  • Cumprimento de obrigações legais

4. Partilha de Dados

Os dados não são vendidos nem partilhados com terceiros, exceto quando necessário para cumprimento legal.

5. Direitos do Utilizador

Nos termos do RGPD, o utilizador pode:

  • Aceder aos seus dados
  • Corrigir ou eliminar dados
  • Retirar consentimento

6. Conservação dos Dados

Os dados são mantidos apenas pelo tempo necessário.
